# HappyPath — Лунный рубеж

Небольшой виджет Windows 11 на панели задач: одна сессия фокуса на задачах Луны длится **20 минут**, а завершённый дневной минимум заполняет один сегмент рабочей недели.

## Что умеет MVP

- клик по виджету — старт, пауза и продолжение сессии;
- после 20 минут — состояние «Рубеж взят»; следующий клик начинает новую сессию без повышения дневной нормы;
- пять сегментов показывают рабочие дни текущей недели с хотя бы одной завершённой сессией;
- увеличенный до 36 px растровый портрет женского лунного демона остаётся на виджете во всех состояниях; стартовая подпись — «Нет времени на раскачку», без Unicode-иконок; нижний прогресс показывается только цветной линией без серой подложки;
- активная сессия переживает перезапуск приложения по сохранённому deadline;
- при одновременном запуске с Hunger Timer виджет автоматически встаёт левее него, без перекрытия;
- после клика по панели задач, скрытия или сворачивания окно возвращается на своё место без захвата фокуса;
- автозапуск с Windows выключен по умолчанию и включается только галочкой в меню трея; без явного согласия приложение не изменяет реестр, отключение сохраняется после перезапуска;
- статистика накапливается в append-only JSONL и восстанавливается после перезапуска;
- завершение сессии записывается ровно один раз, даже после аварии между журналом и сохранением состояния;
- CSV можно обновить через меню иконки в системном трее.

Planner остаётся источником задач. HappyPath пока не изменяет карточки и не хранит их содержимое — только события таймера и статистику фокуса.

## Данные

По умолчанию файлы находятся в `%APPDATA%\HappyPath\`:

| Файл | Назначение |
|---|---|
| `events.jsonl` | Полная история запусков, пауз, продолжений, сбросов и завершений. Только дополняется. |
| `state.json` | Текущая сессия и deadline для восстановления после перезапуска. |
| `sessions.csv` | Плоская выгрузка всех завершённых сессий для Excel, pandas и других расчётов. Пересоздаётся из полного журнала. |

В каждой JSONL-записи есть версия схемы `v`, время события `ts` в UTC и тип `event`. Время завершения — это фактический deadline сессии, а не момент, когда приложение позднее заметило его окончание.

Пример завершения (значения демонстрационные):

```json
{
  "v": 1,
  "ts": "2026-11-02T09:20:00.000Z",
  "event": "session_completed",
  "session_id": "19...-1234-1",
  "started_at": "2026-11-02T09:00:00.000Z",
  "completed_at": "2026-11-02T09:20:00.000Z",
  "local_date": "2026-11-02",
  "focused_seconds": 1200,
  "duration_seconds": 1200,
  "app_version": "0.1.0",
  "recorded_at": "2026-11-02T09:20:00.120Z"
}
```

В CSV входят: `session_id`, `local_date`, `weekday`, `started_at_utc`, `completed_at_utc`, `focused_seconds`, `focused_minutes`, `duration_seconds`, `app_version`.

## Сборка

Требуются установленные Node.js, Rust и рабочий toolchain Tauri v2 для Windows. Команды ниже — для **PowerShell**:

```powershell
npm ci
npm run test:rust
npm run build
```

Установщик NSIS появится в `src-tauri\target\release\bundle\nsis\`. При переходе на более новую версию он обновляет приложение поверх прежней установки, не показывая страницу с предложением предварительно удалить её. Статистика из `%APPDATA%\HappyPath\` при обновлении сохраняется. Шаблон `src-tauri\nsis\installer.nsi` основан на официальном шаблоне Tauri 2.12.1; повторная установка той же версии и переход на более старую версию сохраняют стандартные предупреждения Tauri.

Быстрая сборка без установщика:

```powershell
npm run tauri build -- --no-bundle
```

## Проверка

Rust unit-тесты:

```powershell
cargo test --manifest-path src-tauri\Cargo.toml --locked
```

Живой E2E запускается против собранного `release\happypath.exe` в среде Python с уже установленным Playwright:

```powershell
python tests\e2e_live.py
```

E2E использует `HAPPYPATH_DATA_DIR`, отдельный WebView2-профиль и трёхсекундные сессии. Все данные пишутся только в `src-tauri\target\e2e-data\`; реальная папка `%APPDATA%\HappyPath\` не затрагивается. Короткая длительность через переменную окружения разрешена только при заданном изолированном `HAPPYPATH_DATA_DIR`; в обычном запуске минимум — 60 секунд, по умолчанию — 20 минут.

Отдельный native-регресс проверяет совместную работу с настоящим Hunger Timer, непересечение окон, реальный клик по панели задач и восстановление после принудительного сворачивания/скрытия:

```powershell
python tests\e2e_taskbar_coexistence.py
```

Для этого теста рядом с каталогом `happypath` должен находиться собранный `hunger-timer`. Его `%APPDATA%` и WebView2-профиль также изолированы; реальная статистика и настройка автозапуска Hunger Timer не изменяются.

## Управление

- **Клик по виджету:** старт → пауза → продолжение; после завершения — новая сессия.
- **Меню трея:** сброс текущего таймера, обновление CSV, открытие папки статистики, выход.
- **Сброс:** незавершённая сессия не добавляет фокусное время; уже накопленная история сохраняется.
